# Native C++ examples

Use these with the **v0.5.0-native.1 experimental prerelease** and SDK 1.5.
They are separate compiled consumers, not Python plugins. Install the matching
platform's example package after the provider.

- [NativePassthrough](NativePassthrough.md): original contexts, linked sources,
  actual held shulker, observations and guarded inventory edits.
- [UICatalogShowcase](../../docs/examples/linux-native-sdk.md): public SDK
  forms/actions and honest catalog/refusal reporting.
- [How-tos and dependency setup](../../docs/NATIVE_EXAMPLES.md).

The other family sources exercise model/SDK contracts. They are not finished
custom merchant, machine, map or equipment implementations. The release ships
only the two loader-compatible consumers above; its manifests identify them.
